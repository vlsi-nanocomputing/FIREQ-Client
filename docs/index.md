# FIREQ-Client

FIREQ-Client is the Python-facing interface of the FIREQ platform. It is used to connect to the server, submit experiment configurations, run YAML-defined experiments, collect the resulting data, and perform basic post-processing tasks such as plotting and export.

The client is designed for three main tasks:

- defining and launching experiments,
- communicating with the server during execution,
- saving, organizing, and post-processing experiment outputs.
